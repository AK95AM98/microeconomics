## About MicroSims

MicroSims are interactive, browser-based simulations that let you explore microeconomic models by changing parameters and observing how the model responds. No installation required.

## Planned Simulations

| Simulation | Chapter | Description |
|---|---|---|
| Production Possibilities Frontier | Ch. 1 | Adjust resources and technology; see how the PPF shifts |
| Supply & Demand | Ch. 2 | Shift supply and demand curves; observe equilibrium changes |
| Elasticity Explorer | Ch. 3 | Change elasticity; see how total revenue responds to price changes |
| Budget Constraint | Ch. 4 | Adjust income and prices; find consumer optimum |
| Cost Curves | Ch. 5 | See how fixed/variable costs shape ATC, AVC, MC |
| Competitive Market | Ch. 6 | Entry and exit in the long run |
| Monopoly Pricing | Ch. 7 | Set price or quantity; see deadweight loss |
| Prisoner's Dilemma | Ch. 10 | Play strategic games against an AI opponent |
| Externality | Ch. 13 | Compare private vs. social optimum; apply a Pigouvian tax |
| Nudge Lab | Ch. 15 | Design choice architectures and see how behavior changes |

---

Simulations are built using Python (Panel/Bokeh) or JavaScript (Observable Plot). Source code will be available in the [GitHub repository](https://github.com/AK95AM98/microeconomics).
